# BurgerHouse – Bestell-App

Web-App zum Bestellen von Burgern, Pizza und Salaten für das fiktive Restaurant **BurgerHouse**. Entstanden als Frontend-Übungsprojekt mit HTML, CSS und JavaScript.

## Funktionen

- Speisekarte mit Gerichten und Preisen
- Warenkorb mit Mengenanpassung und Gesamtsumme
- Anzeige von Lieferkosten und Lieferzeit
- Impressum und Cookie-Einstellungen

## Technologien

HTML5 · CSS3 · JavaScript (ohne Framework)

## Projekt starten

1. Repository klonen: `git clone https://github.com/KonstantinFenzlein/Bestellapp.git`
2. `index.html` im Browser öffnen – eine Installation ist nicht nötig.

## Hinweis

Dies ist ein Lernprojekt. Es gibt keine echte Bestellabwicklung, Adresse und Preise sind Beispieldaten.
